# Monoalphabetic Cipher — C# Encryption

A **C# console application** demonstrating monoalphabetic substitution cipher encryption and decryption.

## What it does

Implements a classic monoalphabetic cipher where each letter of the plaintext is consistently replaced by a corresponding letter from a substitution key. Supports both encryption (plaintext → ciphertext) and decryption (ciphertext → plaintext).

## Tech Stack

- **C#** — .NET console application

## How It Works

A monoalphabetic cipher uses a fixed substitution alphabet. Every occurrence of a given letter is always replaced by the same cipher letter, making it a simple but historically significant encryption technique.

## Getting Started

```bash
dotnet run --project Encryption
```

Follow the console prompts to enter a message and encryption key.
